# Handoff

AI exit interview → living playbook for leadership transitions.

Meta Global AI Developer Hackathon (Indie track).

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The home page renders the Northline Labs fixture playbook from `fixtures/`. It does not call the Meta API.

Copy `.env.example` to `.env.local` and set `MODEL_API_KEY` when the API client lands. `.env.local` stays untracked.
